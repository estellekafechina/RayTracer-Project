# Use Catch2 for unit tests

## Context

The project needs readable unit tests for test-driven development. Alternatives
include GoogleTest, doctest and a custom assertion harness.

## Decision

Use Catch2 3.16.1, fetched by CMake and discovered through CTest.

## Status

Proposed

## Consequences

Tests have expressive assertions and integrate with the existing CTest command.
The first configuration needs network access, Catch2 adds compilation time, and
the project depends on an external framework.
